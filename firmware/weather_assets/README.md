# Weather icons

The SVGs are from [Lucide](https://lucide.dev/), pinned to commit
`f06ac67e33d645c40b8ce19a0419c85c5d7dd751`. Their complete license is in
[`LUCIDE-LICENSE`](LUCIDE-LICENSE). The 28×28 PNGs and `../weather_icons.h` are
generated by `scripts/generate_weather_icons.py` with a slightly heavier stroke
and colours chosen for the transit board. They are embedded in firmware; the
device does not download icons at runtime.

To regenerate on macOS, install `librsvg` and Pillow, then run
`python3 scripts/generate_weather_icons.py` from the repository root.

Open-Meteo's current and daily WMO condition codes select these icons. Current
conditions use sun or moon variants according to `is_day`; the daily icon uses
the day's most severe forecast condition. See
[`weather_model.h`](../weather_model.h) for the complete code mapping.
